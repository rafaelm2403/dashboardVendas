# Dashboard de Vendas

Um projeto de um dashboard corporativo, totalmente robusto e de fácil utilização.

- Realizado em Python
Por seu código ser realizado em python, trata-se de um aplicativo totalmente versátil e de simples uso. Pode-se implementar em vários ambientes.

- Filtragem
É um passo simples e intuitivo dentro do aplicativo: Todos seus possíveis filtros e demais coisas são de fácil visualizaçao e sem demoras.

- Objetivo

Facilitar o dia a dia em diferentes tipos de ambientes, como empresas, escolas, pequenos negócios ou até mesmo em usos pessoais, com vendas e movimentação monetária 
diversa. Pode-se realizar o controle através dele.
